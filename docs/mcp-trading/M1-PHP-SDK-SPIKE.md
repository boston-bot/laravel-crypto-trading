# M1 transport decision: retain PHP

Decision recorded and live-verified October 16, 2026. Use the official PHP MCP SDK `mcp/sdk` **0.8.1**, pinned in `composer.lock`; Laravel owns policy, OAuth credential storage and business state. No Python bridge was needed.

The bounded spike inspected the release source and primary documentation, installed thirteen required dependencies with zero existing dependency upgrades, and exercised the actual SDK through fake PSR-18 responses. Initialization, protocol counteroffers, JSON/SSE, sessions, catalog pagination, tool calls, HTTP errors and denied mutation tests pass. The SDK provides the required transport machinery; no material Python advantage was demonstrated. Source: [official PHP SDK release](https://github.com/modelcontextprotocol/php-sdk/tree/v0.8.1), [client transport documentation](https://github.com/modelcontextprotocol/php-sdk/blob/v0.8.1/docs/client/transports.md).

The narrow Laravel PSR-18 adapter enforces a fixed resource, explicit read-tool allowlisting, no redirects, fake-client testing, HTTP error classification and time/size bounds. It rewinds response streams after Laravel's size check and supplies the SDK-negotiated protocol header. The SDK retains JSON-RPC, session and SSE handling. No LLM client capabilities or arbitrary remote tool invocation are exposed.

Actual app-owned OAuth consent then enabled negotiation of **2025-11-25**, complete discovery of 83 tool schemas, binding of the operator-selected existing account, and successful portfolio/equity position/equity order/symbol/quote reads. Real refresh-token rotation succeeded; another new process read using the persisted renewed credentials. Captured sanitized contracts and automated failure-path/concurrency tests are recorded in [M1 evidence](M1-INTEGRATION-EVIDENCE.md).

Robinhood's observed public-client OAuth flow uses PKCE S256 and `internal` scope. No granular broker-enforced read-only scope is claimed: the application permits only six reviewed read tools. Sources: [Robinhood external-agent onboarding](https://robinhood.com/us/en/support/articles/agentic-trading-overview/), [MCP authorization specification](https://modelcontextprotocol.io/specification/2025-11-25/basic/authorization). Account creation, approvals and brokerage mutations were not part of the spike. Revisit transport choice only if a real protocol change demonstrates an unsupported requirement; do not add a second strategy engine or state writer.
